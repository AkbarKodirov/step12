Q: The expression 6x^4 + 17x^2 + 5 can be rewritten as (3x^2 + a)(2x^2 + b), where a and b are positive integers, or as (3x^2 + c)(2x^2 + d), where c and d are positive nonintegers. What is the value of a + c?
K: 17/2 | 8.5
E: The integer factoring is (3x^2 + 1)(2x^2 + 5), so a = 1. For the other form 2c + 3d = 17 and cd = 5, which gives c = 15/2 (c = 1 gives integers). So a + c = 1 + 15/2 = 17/2.
